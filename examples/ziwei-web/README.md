# 本地紫微斗数排盘网页

这是给不写代码的人用的排盘页面。它调用本仓库里的 `iztro`，在浏览器里生成十二宫命盘。出生日期、性别和时辰不会上传，也不需要账号。

页面只排列星曜和基础资料，不判断吉凶，也不表示算命有效。

## 启动

需要本机已有 Node.js 18 或更新版本，以及 Yarn 1。

在仓库根目录安装排盘库：

```shell
yarn install --frozen-lockfile
```

再进入网页目录，安装页面自己的依赖并启动：

```shell
cd examples/ziwei-web
yarn install
yarn dev
```

终端会显示本地地址，一般是 `http://localhost:5173`。用电脑或手机浏览器打开即可。手机和电脑要在同一个网络时，可以用终端里 `Network` 那一行的地址。

生成静态文件并用本地服务器查看：

```shell
yarn build
yarn preview
```

预览地址一般是 `http://localhost:4173`。不要直接双击 `dist/index.html`，浏览器会拦截这种打开方式下的脚本。

## 怎么填

1. 选择公历或农历。
2. 填写生日。农历可以勾选“这一天在闰月”；如果那一年没有这个闰月，页面会提示，不会改成平月。
3. 选择男或女，再选择出生时辰。
4. 点“生成命盘”。改完资料后可以再点一次。

“填入示例并排盘”会填入公历 2000-08-16、女、寅时，方便先看清版面。这不是你的生日。

## 时辰规则

时辰按钟表分段，和库里的 `timeIndex` 一致：

| 时辰 | 钟表时间 | 序号 |
| --- | --- | --- |
| 早子时 | 00:00–01:00 | 0 |
| 丑时到亥时 | 每两小时一辰 | 1–11 |
| 晚子时 | 23:00–00:00 | 12 |

默认晚子时按次日排盘，农历和星曜与次日早子时相同，页面仍保留你输入的公历日期。勾选“晚子时仍算在当天”后留在当日。

本页不支持真太阳时，也不做出生地经度、时区或夏令时换算。请先自己确定钟表时辰，再来选择。

闰月十五及以前按本月安宫，十六起按下月。这是库的默认 `fixLeap`，页面没有改这条规则。

## 局限

- 只排本命十二宫、主星、辅星、杂曜、命宫、身宫、四柱、五行局和大限岁数。没有流年批命，也没有飞星派、中州派切换。
- 农历依赖库所使用的历表。页面不会另外发明一套历法。
- 没有公网地址。要把页面给别人用，需要你自己有静态网站托管，并把 `yarn build` 得到的 `dist/` 放上去。本仓库没有配置部署。
